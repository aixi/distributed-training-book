!!! note "术语与局部别名"
    我们使用 **All-to-All** 作为这个多对多转置集合操作的规范书面术语（在代码中你可能还会看到 `AlltoAll`、`all_to_all` 等 API 风格的名字）。
    章节级符号横幅可能引入局部别名，例如用 $B_{\text{tok}} = B \cdot S$ 表示批 token 数，同时保留下文定义的全局符号。

## 最小形式化

我们把分布式训练建模为三种资源的相互作用：

- **内存**（每个设备上必须装下的东西）
- **计算**（每步每设备的 FLOPs）
- **通信**（跨链路传输的字节数）

基本代价模型是：

$$T = T_{\text{compute}} + T_{\text{comm}}$$

有重叠时，有效步长为：

$$T_{\text{step}} \approx \max(T_{\text{compute}}, T_{\text{comm}})$$

对通信，我们使用 α-β 模型：

$$T(n) = \alpha + \frac{n}{\beta}$$

## 核心符号（所有部分）

| 符号 | 含义 | 典型单位 |
|---|---|---|
| $\Psi$ | 模型参数数量 | 个 |
| $D$ | 训练 token 数（数据集大小） | token |
| $C$ | 总计算预算 | FLOPs |
| $B$ | 全局批大小（序列数） | 序列/步 |
| $b$ | 每 GPU 批大小（序列数） | 序列/步 |
| $S$ | 序列长度 | token |
| $H$ | 隐层维度 | 维度 |
| $L$ | transformer 层数 | 个 |
| $A$ | 注意力头数 | 个 |
| $V$ | 词表大小 | 个 |
| $P$ | GPU/进程总数 | 个 |
| $F$ | 每 GPU 峰值吞吐 | FLOP/s |
| MFU | 模型 FLOP 利用率 | 比例 |
| HFU | 硬件 FLOP 利用率（含重算） | 比例 |
| $T$ | 时间（依上下文：单步、总计等） | 秒 |
| $R$ | 每 GPU 小时费率 | 美元/小时 |

除非另有说明，每步总 token 数为 $B \cdot S$。

## 扩展律（第二部分）

!!! note "符号复用"
    在第二部分，$\alpha$ 与 $\beta$ 表示扩展律指数。从第三部分起，它们表示网络延迟与带宽。含义由上下文即可判断。

| 符号 | 含义 | 典型值 |
|---|---|---|
| $\alpha$ | 参数扩展指数 | 0.34（Chinchilla） |
| $\beta$ | 数据扩展指数 | 0.28（Chinchilla） |
| $A, B$ | 扩展律常数 | ~400 |
| $L_\infty$ | 不可约损失 | ~1.69 nats |

## 通信（第三–八部分）

| 符号 | 含义 | 典型单位 |
|---|---|---|
| $\alpha$ | 网络延迟（每条消息） | 秒（~μs） |
| $\beta$ | 网络带宽 | 字节/秒 |
| $n$ | 消息大小 | 字节 |
| $n^*$ | 交叉点（$\alpha \cdot \beta$） | 字节 |
| $I_{\text{net}}$ | 通信强度（FLOPs/通信字节） | FLOPs/字节 |
| $I_{\text{mem}}$ | 内存强度（FLOPs/HBM 字节） | FLOPs/字节 |
| $I_{\text{io}}$ | 数据 I/O 强度 | FLOPs/字节 |
| $b_{\text{tok}}$ | 每 token 字节数（来自存储） | 字节/token |
| $\rho$ | 读放大 | 比例 |

## 内存（第五部分）

| 符号 | 含义 | 备注 |
|---|---|---|
| $M_{\text{params}}$ | 参数内存 | $2\Psi$ 字节（FP16） |
| $M_{\text{grad}}$ | 梯度内存 | $2\Psi$ 字节（FP16） |
| $M_{\text{opt}}$ | 优化器状态内存 | $12\Psi$ 字节（AdamW FP32） |
| $M_{\text{act}}$ | 激活内存 | 取决于 $B, S, H, L$ |
| $k$ | 检查点间隔（检查点之间的层数） | 最优 $\sqrt{L}$ |

## 专家并行（第四部分，第 18 章）

| 符号 | 含义 | 备注 |

| $k$ | 每 token 激活专家数 | 1–4 |
| $C_f$ | 容量因子 | 1.0–1.5 |
| $f_i$ | 路由到专家 $i$ 的 token 比例 | 比例 |
| $p_i$ | 专家 $i$ 的平均路由概率 | 比例 |

## 效率（第七部分）

| 符号 | 含义 | 备注 |

## 解读标签

看到带标签的提示框时，按如下方式理解：

- **理论（Theory）**：算法下界与理想化模型。
- **实践（Practice）**：经验范围、框架行为和开销。

## 约定

- **GB/TB** 为十进制（$10^9$/$10^{12}$ 字节）
- **GiB/TiB** 为二进制（$2^{30}$/$2^{40}$ 字节）
- 除非另有说明，FLOP/s 假设 H100 SXM 上的稠密 FP16/BF16（~989 TFLOP/s）
- 完整加速器规格见[硬件假设](hardware-assumptions.md)
