**问题**：一个 10B 参数的模型不会做多步算术；一个 100B 的模型会。这种能力从何而来？损失曲线是平滑的，能力却是突然出现的。我们该如何解释——并预测——这些相变？

## 涌现之谜

把损失对计算量作图：你会得到平滑的幂律。把能力对计算量作图：你常常会得到阶跃函数。

```
损失                          能力
  │                              │
  │╲                             │        ┌────
  │ ╲                            │        │
  │  ╲                           │        │
  │   ╲                          │────────┘
  │    ╲___                      │
  └────────────→ 计算量          └────────────→ 计算量
    平滑衰减                       急剧转变
```

这就是**涌现之谜（emergence puzzle）**：平滑的损失改善掩盖了离散的能力获得。

## 相变的类型

### 类型 1：能力涌现

某些能力会在规模化时突然出现：

| 能力 | 大致阈值 | 说明 |
|------|----------|------|
| 上下文学习（in-context learning） | ~1B 参数 | 在 GPT-2（1.5B）中观察到；更小的模型中也见过有限形式 |
| 思维链推理（chain-of-thought reasoning） | ~60B 参数 | Wei 等人（2022）；阈值取决于评估方法 |
| 多步算术 | ~100B 参数 | 与提示方式高度相关 |
| 心智理论（theory of mind） | ~100B+ 参数 | 争议极大——许多研究者质疑 LLM 是否具备这种能力 |

!!! warning "关于涌现的警告"
    Schaeffer 等人（2023）指出，许多“涌现”能力可能是离散评估指标的假象，而非真正的相变。当使用连续指标（例如 token 级准确率而不是完全匹配）时，许多表面上的不连续会变成平滑改善。上述阈值只是近似值、依赖具体模型，应保持适当的怀疑。

**数学模型**：设能力 $c$ 通过下式依赖损失：

$$P(c | L) = \text{sigmoid}\left(\frac{L_c - L}{\tau}\right) = \frac{1}{1 + e^{-(L_c - L)/\tau}}$$

其中：

- $L_c$：能力 $c$ 的临界损失阈值
- $\tau$：转变锐度

当 $\tau \to 0$ 时，转变变成阶跃函数。

### 类型 2：训练动力学阶段

优化过程本身也有阶段：

**阶段 1：随机猜测**
- 损失 ≈ log(词表大小)
- 模型输出均匀分布
- 持续：最初几百步

**阶段 2：一元语法学习**
- 模型学习 token 频率
- 初始损失快速下降
- 持续：约训练的前 1%

**阶段 3：二元/多元语法**
- 学到局部相关性
- 改善变慢
- 持续：约训练的前 5%

**阶段 4：语义学习**
- 长程依赖
- 幂律区间
- 持续：训练的大部分

**阶段 5：记忆化**
- 训练损失继续下降
- 验证损失趋于平台
- 过拟合开始

### 类型 3：Grokking（顿悟泛化）

一种现象：
1. 模型记住训练数据（训练损失 → 0）
2. 验证损失保持高位（没有泛化）
3. 突然，在长时间训练后，验证损失下降
4. 模型“grokked”了底层模式

```
损失
  │
  │ 训练         验证
  │    ↓            ↓
  │    ●───────────────────
  │     ╲
  │      ╲    ●●●●●●╲
  │       ╲          ╲
  │        ╲____      ╲____
  │                 ↑
  └─────────────────┼────→ 步数
              Grokking 点
```

Grokking 表明泛化是通过一个独立的相变发生的，而不是逐渐改善。

## 4+3 阶段模型

Caballero 等人（2023）在 $(D_{\text{data}}, D_{\text{task}})$ 平面中发现了更丰富的阶段结构，其中 $D$ 衡量复杂度。

### 四个主要阶段

**阶段 I：模型容量受限**

模型太小，无法表示目标函数。

$$L \approx L_{\infty}(\Psi) = \frac{A}{\Psi^\alpha}$$

损失由模型规模决定，与数据或优化无关。

*症状*：

- 增加更多数据没有帮助
- 训练更久没有帮助
- 需要更大的模型

**阶段 II：优化器噪声受限**

梯度噪声阻止收敛到真正的最小值。

$$L \approx L_{\text{opt}}(B, \eta) = \frac{\sigma^2}{B \cdot f(\eta)}$$

其中 $\sigma^2$ 是逐样本梯度的方差，$B$ 是批大小，$\eta$ 是学习率，$f(\eta)$ 刻画学习率的影响。

*症状*：

- 更大的批大小有帮助
- 学习率调优非常关键
- 损失在某个下限附近波动

**阶段 III：数据受限**

没有足够的数据来学习任务。

$$L \approx \frac{B}{D^\beta}$$

*症状*：

- 更多数据直接降低损失
- 模型可能过拟合
- 验证损失 >> 训练损失

**阶段 IV：计算最优**

Chinchilla 最优性成立的平衡区间。

$$L = \frac{A}{\Psi^\alpha} + \frac{B}{D^\beta} + L_\infty$$

*症状*：

- 模型规模和数据都重要
- 平滑的幂律缩放
- 最优分配为 $D \approx 20\Psi$

### 三个过渡区

阶段之间的行为很复杂：

**I→IV 过渡**：随着 $\Psi$ 增大，你从容量受限走向平衡。

**II→IV 过渡**：随着 $B$ 增大，优化器噪声下降，直到数据/计算限制占主导。

**III→IV 过渡**：随着 $D$ 增大，数据限制放松。

## 双下降

一个引人注目的非单调现象：

```
测试损失
    │
    │  ●
    │   ●        ●
    │    ●      ● ●
    │     ●    ●   ●
    │      ●  ●     ●
    │       ●●       ●────
    │         ↑
    └─────────┼──────────→ 模型规模
         插值阈值
```

**经典区间**（小模型）：越大 = 泛化越好

**插值阈值**（模型刚好拟合训练数据）：过拟合峰值

**现代区间**（过参数化）：越大 = 又变得更好

发生这种现象是因为：
1. 小模型欠拟合 → 高偏差
2. 中等模型记忆化 → 高方差
3. 大模型找到平滑插值 → 低方差

**对分布式训练而言**：不要在插值阈值处停下。要坚持推进到现代区间。

## 涌现能力：更深入的观察

### 指标很重要

Wei 等人（2022）表明，涌现取决于你如何测量：

| 指标 | 看起来像涌现吗？ |
|------|------------------|
| 准确率（完全匹配） | 是 |
| Token 级对数似然 | 否 |
| 部分得分 | 有时 |

用对数似然衡量，能力是平滑改善的。用完全匹配准确率衡量，它们看起来是突然出现的。

**含义**：“涌现”可能是离散评估指标的假象，而不是模型内部表征的性质。

### 电路形成假说

能力可能在内部“电路”完成时出现：

1. 各个组件逐渐发展
2. 电路需要所有组件齐备
3. 当最后一个组件形成时，能力出现

就像建桥：地基的进展是看不见的，直到桥面合龙。

### 预测涌现

给定当前趋势，能力 $c$ 何时会出现？

**方法 1**：外推损失曲线，估计 $L_c$

$$\Psi_c \approx \left(\frac{A}{L_c - L_\infty}\right)^{1/\alpha}$$

**方法 2**：使用线性探针

在中间表征上训练一个线性分类器。当线性探针准确率超过随机水平：

- 该表征已经包含这种能力
- 完整能力可能很快出现

**方法 3**：部分能力指标

设计分级的评估。寻找能预测离散阈值的平滑改善。

## 对分布式训练的含义

### 1. 扩展规划

知道你在哪个阶段：

| 阶段 | 优化策略 |
|------|----------|
| 容量受限 | 扩大模型（为 TP/PP 增加 GPU） |
| 数据受限 | 改进数据流水线 |
| 优化器受限 | 调整超参数，增大批大小 |
| 计算最优 | 平衡扩展 |

### 2. 检查点策略

在相变附近：

- 更频繁地保存检查点
- 能力可能在两次评估之间出现
- 不要在相变前一刻停下

### 3. 批大小动力学

在优化器噪声受限阶段：

- 更大的批大小有帮助
- 可以随训练增大批大小

在数据受限阶段：

- 批大小对损失没有帮助
- 但更大的批 = 更快的迭代

### 4. 课程效应

一些证据表明训练顺序会影响相变：

- 先易后难可能加速阶段 I→IV 的过渡
- 过早加入难样本可能推迟 grokking

### 5. 算力分配

如果目标是某种特定能力：

$$C_{\text{needed}} = 6 \cdot \Psi_c \cdot D_{\text{opt}}(\Psi_c)$$

其中 $\Psi_c$ 是能力阈值对应的模型规模。

算力低于 $C_{\text{needed}}$ 会浪费一切——你永远达不到阈值。

## 扩展假说

扩展假说（scaling hypothesis）的一种强形式：

> 只要有足够的算力，任何能力都会涌现。

支持证据：

- 更大的模型持续获得新能力
- 尚未发现最终不会出现的能力

反对证据：

- 某些能力可能需要架构改变
- 数据质量限制可能是根本性的
- 算力/时间在实践中可能不可行

**实践立场**：假设能力会涌现，但为阈值的不确定性做好规划。

## 案例研究：算术能力

追踪多位数加法随规模的变化（仅作示意——具体数字依赖模型和提示）：

| 模型规模 | 2 位数 | 3 位数 | 4 位数 | 5 位数 |
|----------|--------|--------|--------|--------|
| 1B | ~95% | ~60% | ~10% | ~0% |
| 10B | ~99% | ~90% | ~50% | ~5% |
| 100B | ~99% | ~99% | ~85% | ~40% |
| 500B | ~99% | ~99% | ~95% | ~80% |

*注：这些数字是近似值，仅用于说明总体模式。实际准确率高度依赖具体模型、训练数据、提示格式和评估方法。*

每种位数复杂度都有自己的相变。位数越多 = 阈值越高。

这表明能力具有**嵌套的相结构**：更容易的变体先出现。

## 练习题

1. **阶段识别**：一个 10B 模型在 200B token 上训练，训练损失 2.1，验证损失 2.3。把数据增加到 500B token 后，训练损失降到 2.0，但验证损失仍为 2.3。这个模型处于哪个阶段？

??? success "解答"
    **观察：**

    | 条件 | 训练损失 | 验证损失 |
    |------|----------|----------|
    | 200B token | 2.1 | 2.3 |
    | 500B token | 2.0 | 2.3 |

    **关键指标：**

    1. 增加数据时验证损失没有改善
    2. 训练损失继续下降（2.1 → 2.0）
    3. 训练/验证损失之间存在差距且持续存在

    **诊断：阶段 I——容量受限**

    模型容量不足以更好地泛化。增加数据改善了训练损失（更多优化步），但没有改善验证损失（表征瓶颈）。

    $$L_{\text{val}} \approx L_\infty(\Psi) = \frac{A}{\Psi^\alpha} + \text{irreducible}$$

    **排除其他阶段的证据：**

    | 阶段 | 预期行为 | 是否观察到？ |
    |------|----------|--------------|
    | 数据受限 | 更多数据 → 更低的验证损失 | 否 ✗ |
    | 优化器受限 | 大批大小 → 更低损失 | 未测试 |
    | 计算最优 | $\Psi$ 和 D 都重要 | 只有 $\Psi$ 重要 |

    **建议**：扩大模型规模（增大 $\Psi$），而不是增加数据或训练时间。

2. **涌现预测**：某能力在 50B 参数时达到 50% 准确率。在 10B 参数时，准确率为 5%。假设转变遵循 $\tau = 0.1$ nats 的 sigmoid，估计该能力的损失阈值 $L_c$。

??? success "解答"
    **使用涌现模型：**

    $$P(c | L) = \text{sigmoid}\left(\frac{L_c - L}{\tau}\right) = \frac{1}{1 + e^{-(L_c - L)/\tau}}$$

    **由 50B 数据点（50% 准确率）：**

    在 50% 准确率时，sigmoid 的参数为 0：

    $$\text{sigmoid}(0) = 0.5 \implies \frac{L_c - L_{50B}}{\tau} = 0$$

    $$\boxed{L_c = L_{50B}}$$

    **由 10B 数据点（5% 准确率）：**

    $$0.05 = \frac{1}{1 + e^{-(L_c - L_{10B})/\tau}}$$

    求解指数：

    $$1 + e^{-(L_c - L_{10B})/0.1} = 20$$

    $$e^{-(L_c - L_{10B})/0.1} = 19$$

    $$-(L_c - L_{10B})/0.1 = \ln(19) = 2.94$$

    $$L_c - L_{10B} = -0.294 \text{ nats}$$

    **估计损失：**

    使用缩放定律 $L(\Psi) \propto \Psi^{-\alpha}$，$\alpha \approx 0.34$：

    $$\frac{L_{10B} - L_\infty}{L_{50B} - L_\infty} = \left(\frac{50}{10}\right)^{0.34} = 5^{0.34} = 1.70$$

    如果 $L_{50B} = L_c$ 且 $L_{10B} = L_c + 0.294$：

    能力阈值 $L_c$ 大约等于 **50B 模型在给定训练阶段达到的损失**。

    **解读**：要预测能力何时出现，外推损失曲线，找到 $L = L_c$ 的时刻。

3. **双下降**：你正在训练一个模型，观察到测试损失上升。你有算力可以选择 (a) 训练更久，或 (b) 把模型规模扩大到 2×。哪种更可能有帮助，为什么？

??? success "解答"
    **分析情况：**

    测试损失上升表明我们接近 **插值阈值**（双下降峰值）。

    ```
    测试损失
        │
        │   ●  ← 你在这里
        │  ● ●
        │ ●   ●
        │●     ●
        │       ●────
        └────────────→ 模型规模 / 训练时间
    ```

    **选项 (a)：训练更久**

    - 最初可能加重过拟合
    - 最终可能进入 grokking（如果任务允许）
    - 有风险：可能永远无法恢复

    **选项 (b)：把模型扩大 2×**

    - 进入过参数化区间
    - 大模型能找到更平滑的解
    - 更可能到达双下降的“现代区间”

    **建议：(b) 把模型扩大 2×**

    | 选项 | 预期结果 | 风险 |
    |------|----------|------|
    | 训练更久 | 可能 grokking，但不确定 | 可能永远无法恢复 |
    | 扩大 2× | 很可能进入现代区间 | 算力成本 |

    **数学依据：**

    在插值阈值处：

    $$\Psi \approx D_{\text{train}}$$

    在保持 $D$ 不变的情况下扩展到 $2\Psi$：

    $$\frac{\Psi_{\text{new}}}{D} = 2 \gg 1$$

    这稳稳进入过参数化区间，在那里隐式正则化有助于泛化。

4. **能力目标**：你需要思维链推理，它大约在 60B 参数时出现。你的算力预算是 $C = 10^{23}$ FLOPs。这足够吗？如果不够，需要多少算力？

??? success "解答"
    **60B Chinchilla 最优所需算力：**

    使用 $D^* = 20\Psi$ 和 $C = 6\Psi D$：

    $$C_{\text{needed}} = 6 \times \Psi \times 20\Psi = 120\Psi^2$$

    $$C_{\text{needed}} = 120 \times (60 \times 10^9)^2 = 120 \times 3.6 \times 10^{21}$$

    $$C_{\text{needed}} = 4.32 \times 10^{23} \text{ FLOPs}$$

    **对比：**

    | 预算 | 所需 | 足够吗？ |
    |------|------|----------|
    | $10^{23}$ | $4.32 \times 10^{23}$ | **否**（差 4.3×） |

    **$C = 10^{23}$ 下的选项：**

    **选项 1：更小的 Chinchilla 最优模型**
    $$\Psi^* = \sqrt{\frac{10^{23}}{120}} = 2.89 \times 10^{10} \approx 29\text{B}$$

    这低于 60B 阈值——**思维链不会涌现**。

    **选项 2：欠训练的 60B 模型**
    $$D = \frac{C}{6\Psi} = \frac{10^{23}}{6 \times 60 \times 10^9} = 278\text{B token}$$

    Token/参数 = $278/60 = 4.6$（严重欠训练）

    如果能力主要取决于模型规模而不是训练，这可能可行。

    **建议：**

    $$\boxed{C_{\text{needed}} = 4.32 \times 10^{23} \text{ FLOPs}}$$

    要保证思维链，预算需要多 4–5 倍算力，或者接受使用欠训练 60B 模型的风险。

5. **Grokking 检测**：你会如何修改训练监控来尽早检测 grokking？你会追踪哪些指标？

??? success "解答"
    **Grokking 特征：**

    1. 训练损失 → 0（记忆化）
    2. 验证损失保持高位
    3. 长时间平台期
    4. 验证损失突然下降（grokking）

    **要追踪的指标：**

    | 指标 | 目的 | Grokking 信号 |
    |------|------|---------------|
    | 训练/验证损失差 | 泛化 | 在 grokking 前很大且稳定 |
    | 权重范数 $\|W\|$ | 正则化进展 | 在 grokking 期间下降 |
    | 梯度范数 $\|\nabla L\|$ | 优化动力学 | 转变前出现尖峰 |
    | Hessian 特征值 | 损失景观 | 锐度下降 |
    | 线性探针准确率 | 内部表征 | 在 grokking 前改善 |

    **实现：**

    ```python
    # 在训练过程中追踪这些指标
    metrics = {
        'train_loss': [],
        'val_loss': [],
        'generalization_gap': [],  # val - train
        'weight_norm': [],
        'gradient_norm': [],
        'probe_accuracy': [],  # 在验证集上做线性探针
    }

    # Grokking 检测启发式规则
    def detect_grokking_potential(metrics, window=1000):
        # 条件 1：训练损失很低，验证损失很高
        train_converged = metrics['train_loss'][-1] < 0.1
        val_high = metrics['val_loss'][-1] > 0.5

        # 条件 2：差距在许多步内保持稳定
        gap_stable = std(metrics['generalization_gap'][-window:]) < 0.01

        # 条件 3：权重范数仍在下降
        weight_decreasing = metrics['weight_norm'][-1] < metrics['weight_norm'][-window]

        return train_converged and val_high and weight_decreasing
    ```

    **可操作建议：**

    1. **不要过早停止**：如果训练损失低但验证损失高，grokking 可能即将到来
    2. **增大权重衰减**：可以加速 grokking
    3. **频繁保存检查点**：在潜在转变附近保存模型
    4. **使用线性探针**：作为表示学习的早期预警

    **关键洞察：** Grokking 表明从记忆化到泛化的转变。追踪权重动力学，而不只是损失。

## 关键要点

1. **平滑损失掩盖离散能力**：损失逐渐改善；能力突然出现。

2. **存在四个阶段**：容量受限、优化器受限、数据受限和计算最优。

3. **双下降是真实存在的**：不要在插值阈值处停下——要坚持穿过去。

4. **涌现可能依赖指标**：使用合适的指标来追踪能力进展。

5. **了解你的阶段**：不同阶段需要不同的优化策略。

6. **为阈值做规划**：如果目标是一种能力，确保有足够算力达到其阈值。
